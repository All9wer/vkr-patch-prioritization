# План ВКР

## Глава 1. Анализ предметной области

- процесс управления уязвимостями и место приоритизации в нём
- CVSS, EPSS, CISA KEV, БДУ ФСТЭК
- методика ФСТЭК по оценке критичности уязвимостей (2025)
- существующие решения, сравнительная таблица
- постановка задачи

В коде: базовые линии и отчёт (`experiments/results/`) дают цифры для постановки задачи.

## Глава 2. Модель приоритизации

- источники данных и признаки
- прогноз эксплуатируемости
- учёт контекста инфраструктуры
- где можно применить языковые модели
- архитектура системы

В коде: `collectors/`, `ranking/`, `context/`, `llm/`.

## Глава 3. Реализация и эксперимент

- реализация
- набор данных и методика эксперимента
- сравнение с CVSS, EPSS и методикой ФСТЭК
- проверка учёта контекста на стенде

В коде: `dataset.py`, `evaluation/`, методика в [methodology.md](methodology.md).
